# أهداف الموثوقية وسياق الأحداث

## الخطوات

في سجل المراقب، اختر 24 ساعة أو 7 أيام أو 30 يومًا أو نطاقًا مخصصًا بالتوقيت المحلي ضمن السجل المحتفظ به. يحدّث زر التحديث النطاقات المتحركة. تعرض الصفوف اليومية بتوقيت UTC الإتاحة وتغطية الرصد ومدة الطلب أو استعلام DNS أو الاتصال. مدة تشغيل مهمة النبض ليست زمن استجابة الطلب.

## المناطق الزمنية

تتبع أوقات المراقبات والحوادث التفضيلات ← المنطقة الزمنية للحساب، أو منطقة المتصفح عند اختيارها. للنطاقات المخصصة وأوقات التعليقات، استخدم المنطقة الموضحة بجوار الحقول. تبقى فترات تقارير SLA والاتجاهات اليومية بتوقيت UTC صراحة؛ لا يغيّر تعديل منطقة العرض حدود هذه التقارير.

## السلوك

تحسب الإتاحة المرجحة بالمدة وقت Up مقسومًا على الوقت المرصود. يستهلك Down وDegraded ميزانية التعطل. هذا القياس منفصل عن نسبة نجاح الفحوص. تغطي كل ملاحظة جديدة فترة مهيأة واحدة كحد أقصى، بسقف سبعة أيام، وتنتهي قبل ذلك عند الملاحظة التالية. يبقى السجل السابق بلا ملاحظة مسجلة والفجوات بعد هذا الأفق مجهولًا. وقت النبض الذي لم يصل أبدًا مجهول. تستمر مواعيد النبض في تحديد الحالة الفعلية؛ لا تستنتج هذه التقديرات صحة تاريخية مستمرة من عينة قديمة.

توضح التغطية الجزء المرصود من النطاق. لا يمنح الوقت المجهول مدة مسموحة للتعطل. يسمح نطاق مرصود بالكامل لمدة 30 يومًا عند 99.9% بتعطل قدره 2,592 ثانية بالضبط (43 دقيقة و12 ثانية). تقلل التغطية الجزئية المدة المسموحة إلى الوقت المرصود المؤهل. بلا وقت مرصود، تكون نسبة الإتاحة والميزانية مجهولتين. لا تنخفض الميزانية المتبقية عن الصفر؛ يُسجل التجاوز منفصلًا.

## الأهداف والتعليقات

لا تغير الأهداف الاختيارية الفحوص أو التنبيهات أو الحالة المقاسة أو ملفات PDF لاتفاقية SLA أو التقارير الشهرية القائمة. تستخدم ميزانية الإتاحة الهدف الحالي كمرجع واضح. يستخدم الالتزام بزمن الاستجابة السياسة المسجلة مع كل ملاحظة، ويحسب فقط ملاحظات Up/Degraded الصالحة ويشمل المساواة الدقيقة. ينشئ تغيير الهدف إصدارًا؛ لا يكرر حفظ الإعدادات المتطابقة الإصدار. تبقى الإصدارات السابقة ظاهرة ضمن السجل المحتفظ به.

تعديل الصيانة اختياري ومنفصل عن النتائج الأصلية. تُستبعد فقط الفترات المسجلة بسياسة استبعاد مفعلة؛ تُحسب الفترات المتداخلة مرة واحدة. لا يستبعد كتم التنبيهات وقتًا مقاسًا مطلقًا. لا تعيد تغييرات الجداول اللاحقة كتابة الفترات المسجلة. بلا وقت معدل مؤهل، تكون النسبة والميزانية المعدلتان مجهولتين. لا يعيد هذا العرض التشغيلي تعريف عقد SLA.

## القيم الخاصة والحدود

تحتوي العلامات الخاصة على وقت وبيئة وإصدار ووصف قصير ورابط HTTP(S) عام اختياري بلا بيانات اعتماد أو استعلام أو جزء مرجعي. هي خاصة بالمالك ولا تظهر في صفحات الحالة العامة. تُحجب أسرار الطلب المعروفة؛ مع ذلك لا تدخل أسرارًا في هذه الحقول. تشير العلامات إلى ارتباط، لا سبب مثبت. استخدم أوقاتًا ضمن السجل المحتفظ به حتى الحاضر فقط؛ تعرض الصفحات العناصر الأقدم بترتيب ثابت حسب الوقت والمعرّف.

يحمّل تصدير النطاق المعروض لقطة القياسات التشغيلية المطابقة للعرض، بما فيها النطاق ووقت الحساب والتغطية والسياسة. ليس ملف SLA PDF أو إرسالًا شهريًا أو نسخة احتياطية للتعافي. تتوفر ملفات SLA PDF والتقارير الشهرية أيضًا لكل حساب.

يمكن لكل حساب استخدام مفاتيح API بنطاق `read` للقراءة و`full` للكتابة. أرسل مفتاح الحساب عبر `Authorization: Bearer`، ولا تضعه في رابط.

## مثال

القراءة: GET /api/v1/monitors/ID/reliability?from=2026-10-09T00%3A00%3A00.000Z&to=2026-10-10T00%3A00%3A00.000Z

الإدراج: POST /api/v1/monitors/ID/annotations مع JSON {"at":"2026-10-10T00:00:00.000Z","environment":"staging","version":"v2","text":"رُصد نشر الإصدار","link":null}. يعيد الإنشاء 201. تسمح قراءة GET للمسار نفسه مع from/to وlimit/cursor الاختياريين بتصفح العلامات الخاصة. لا تضع مفتاح API في عنوان URL.

يتطلب السجل العام تفعيلًا صريحًا من مالك صفحة منشورة. يعرض سبعة أيام UTC مكتملة مع الإتاحة الأصلية والتغطية وتعديل الصيانة المنفصل والأزمنة محددة النوع. تطلب الصفحة جميع المكونات المحددة في طلب واحد عند التوسيع؛ لا يُحمّل كل جدول إلا عند فتح لوحته. تبقى الفجوات مجهولة. لا تُعرض الأسماء الخاصة أو عناوين URL أو الملاحظات أو الأهداف أو معرّفات المراقبين أو الأسرار. زمن الطلب ليس زمن تحميل صفحة المتصفح. يجعل هذا النشر الاختياري قياسات الإتاحة والأداء ظاهرة؛ راجع هذا القرار قبل التفعيل.

يعرض سياق الحوادث جميع الحوادث المقاسة التي تتقاطع مع النطاق المعروض عبر الصفحات. تُقص المدد عند الحدين، بما فيها الحوادث المفتوحة سابقًا والتي تعافت لاحقًا. ترتب ملخصات الأسباب أحدث 1,000 حادث مطابق حسب مجموع المدد؛ يظهر تنبيه لملخص جزئي عند تجاوز هذا الحد، ويبقى التصفح كاملًا. قد تتداخل الحوادث المتزامنة، لذلك لا تمثل مجاميع المدد حساب الإتاحة. تُحجب الأسباب الخاصة باستخدام إعداد الطلب الحالي. لا يثبت توقيت العلامة وحده سبب الحادث.

## استكشاف المشكلات

تحقق أولًا من المراقب والفترة والإعدادات المحفوظة. غياب الملاحظات لا يعني سلامة الخدمة. بعد الخطأ، احتفظ بالمسودة وصحّح الحقل أو المتطلب المشار إليه ثم أعد المحاولة عمدًا. إذا انتهت صلاحية المعاينة، أنشئ معاينة جديدة وراجعها قبل التطبيق.
