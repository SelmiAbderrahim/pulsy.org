# تدهور زمن الاستجابة والتعافي المستقر

## الخطوات

في الإنشاء أو الإعدادات وسّع زمن الاستجابة وسياسة التنبيه وفعّلها. تتوفر لكل حساب. تحتفظ الإضافة السريعة والمراقبة دون سياسة بسلوكها. تعطيلها صراحة بـ null يعيد السلوك القديم. تعديل السياسة أو استبدالها جماعيًا بسياسة مختلفة يعيد العدادات؛ السياسة المطابقة والتعديلات الأخرى تحفظها. لا تُحذف الفحوص أو الحوادث أو إيصالات التسليم.

## السلوك

عتبات الزمن اختيارية. فعّل اكتشاف البطء لضبط الحد الأعلى وعدد الفحوص المتتالية. المدة هي مللي ثانية هذا الطلب HTTP وتشمل قراءة استجابة القواعد، وليست وقت تحميل المتصفح. يجب أن تنجح جميع القواعد على الاستجابة نفسها قبل اعتبار الزمن. عدم الوصول والحالة غير المقبولة وفشل القواعد تُعدّ تعطلًا وفق عتبة الفشل الحالية. مع السياسة، الاستجابة غير المتوقعة أقل من 400 فشل؛ تحتفظ المراقبة القديمة بالتدهور في هذه الحالة.

الاستجابة الصالحة الأكبر قطعًا من الحد الأعلى عينة بطيئة. يغيّر العدد المتتالي المحدّد الحالة من سليم إلى متدهور. المساواة ليست بطئًا. الاستجابة الصالحة الأصغر من عتبة التعافي أو المساوية لها تزيد تقدّم التعافي؛ المساواة تُحسب والصفر مدعوم. لا تتجاوز عتبة التعافي الحد الأعلى. القيم بينهما تصفّر تقدم التعافي وتحفظ التعطل أو التدهور الحالي. التعطل له الأولوية ويبقى حتى اكتمال عدد التعافي، حتى لو كانت الاستجابات التالية صالحة وبطيئة. دون عتبات زمنية، كل استجابة صالحة تزيد التعافي. العدادات 1–10، العتبات حتى 60000 مللي ثانية، وفاصل التنبيهات حتى 3600 ثانية.

يعرض المراقب الحالة المحتفظ بها والتقدم؛ يحتفظ تاريخ الفحوص بعينات سليم/متعطل/متدهور الخام. يبقى حادث مقاس واحد مفتوحًا خلال بطء مستمر يتحول إلى تعطل، ويغلقه التعافي المحسوب. تحتفظ أسباب البطء بالمدة والحد عند حدوثها. يعرض الرسم الحد الحالي؛ المدد المفقودة فجوات. تغيير السياسة لا يعيد تصنيف الفحوص القديمة.

حرج وتحذير يستخدمان القنوات المحدّدة أو الافتراضية. معلوماتي يسجل الفشل والحوادث دون تنبيه تشغيلي، ويظل محسوبًا في التوافر الخام. للقنوات خيار صريح للإشعار بالتدهور، معطّل مبدئيًا للقنوات الجديدة والقديمة؛ لا تتغير اختيارات التعطل والتعافي. انتهاء TLS له سياسة مستقلة.

تدخل انتقالات السياسة طابورًا دائمًا. ينتظر تنبيه الفشل الجديد انتهاء الفاصل منذ آخر تسليم فعلي؛ قد تزيد الصيانة والكتم التأخير. يتجاوز التعافي الفاصل ولا يصل إلا للوجهات نفسها ذات إيصال نجاح محفوظ للواقعة الحالية، بما فيها تنبيه تدهور وصل بينما تأخر تنبيه التعطل اللاحق أو عُطّل. يحفظ التصعيد الهوية. تعطيل السياسة يحفظ مطابقة الإيصالات والتعافي الدائم لواقعة مهيأة. لا يعيد تدهور قديم جديد استخدام إيصالات واقعة متعافية.

## مثال

يعرض سجل الإرسال المحاولات والرسائل المقبولة أو الفاشلة أو المحجوبة بحسب الأدلة المتاحة. قبول المزود لا يثبت وصول الرسالة إلى صندوق الوارد. راجع الخطأ قبل إعادة المحاولة؛ قد تكون النتيجة غير مؤكدة وقد تتكرر الرسالة.

اختبار الإعداد فحص واحد صريح يعرض صلاحية القواعد والزمن الخام لا الحالة المحتفظ بها بعد عدة فحوص. لا يغيّر العدادات أو التاريخ أو الحوادث أو الإشعارات. POST يتطلب تأكيدًا لآثاره المحتملة؛ لا يختبر الحفظ تلقائيًا.

تتوفر الواجهة بالإنجليزية والعربية والفرنسية والألمانية والإسبانية. تعرض قراءة REST السياسة والعدادات غير السرية. يمكن لكل حساب استخدام مفاتيح API بنطاق `read` للقراءة و`full` للكتابة. أرسل مفتاح الحساب عبر `Authorization: Bearer`، ولا تضعه في رابط.

## استكشاف المشكلات

تحقق أولًا من المراقب والفترة والإعدادات المحفوظة. غياب الملاحظات لا يعني سلامة الخدمة. بعد الخطأ، احتفظ بالمسودة وصحّح الحقل أو المتطلب المشار إليه ثم أعد المحاولة عمدًا. إذا انتهت صلاحية المعاينة، أنشئ معاينة جديدة وراجعها قبل التطبيق.
