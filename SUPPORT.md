# Support

Pulsy is community-supported open-source software. Community support is
best-effort and does not include a response-time guarantee.

## Questions and self-hosting help

Use the repository's
[question template](https://github.com/SelmiAbderrahim/pulsy/issues/new/choose)
for setup questions and deployment advice. Before posting, check the
[README](README.md) and documentation under [`docs/`](docs/).

## Bugs and feature requests

Use [GitHub Issues](https://github.com/SelmiAbderrahim/pulsy/issues) for
reproducible bugs and scoped feature proposals. Search existing issues first
and remove secrets, credentials, private URLs, and personal data from logs.

## Security vulnerabilities

Do not report vulnerabilities in a public issue or discussion. Follow the
private reporting instructions in [SECURITY.md](SECURITY.md).

## Hosted deployments

Operators who enable the optional hosted support workflow are responsible for
publishing their own contact route and response expectations. Those promises do
not apply to community support for this repository.
